# Tutorial Structures

Structures made to teach the player of game mechanics without the need of documentation or wikia.

For now, it only adds 3 structures, but more will be added inshaAllah.

<details>
<summary>Structures</summary>


Campfire Tutorial

Teaches the player how to use a campfire. It has a campsite with an unlit campfire containing meat at the middle.


Respawn Anchor Tutorial

Teaches the player how to use a Respawn Anchor, has a respawn anchor activated to 1/4 and has glowstone around it (to give the player the hint that they should put glowstone into it).

Brewing Tutorial

Teaches the player the basics of the brewing stand, and teaches them how to make an awkward potion and a fire resistance potion.

The ground level contains a barrel with materials for awkward potions, while the attic contains a barrel with more materials for making a fire resistance potion

</details>

### How do I install...

On [Github](https://github.com/friedegg796/Muslimdiscs), you have to install zip, unzip it, open your terminal, cd into
it, and then run <code>./gradlew build </code> (Requires Java), then look for the jar file in build/libs of the unzipped
folder (Unreleased versions).

Or go to the [releases](https://github.com/friedegg796/TutorialStructures/releases), pick the release you want, and
install the jar file
